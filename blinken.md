##### Blinkenlights SCSI Adapter Kit

{% include carousel3.html %}

This is Blinkenlights SCSI Adapter kit for use with any SCSI situation where you need to convert a 50 pin connector to either a C50 centronics connector, DB25 connector or a Powerbook connector. You will need to solder the connectors on, but its all through hole and resonably easy. The last photo is a fully assembled unit for reference. 

It has a line of blue led's to show activity on the SCSI bus so can be useful it testing and debugging.

* Kit version (through hole soldering required)
* Lovely blue leds show SCSI bus activity
